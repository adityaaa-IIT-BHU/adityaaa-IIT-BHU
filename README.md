# Aditya Acharya

Biomedical Engineering at IIT (BHU) Varanasi. Currently a research intern at **NIMS** (National Institute for Materials Science) in Tsukuba, Japan.

I build systems that pull structure out of messy scientific inputs — papers, charts, medical images, video — and turn them into data you can actually compute on.
